## 一、环境与运行步骤

### 1) 依赖安装
```bash
cd /Users/raywu/.openclaw/workspace/pdf-context-translator
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2) 启动服务（目标端口）
```bash
uvicorn app.main:app --reload --port 8000
```
打开：`http://127.0.0.1:8000`

> 若 8000 已被占用：先释放端口再重启（本次自动化测试临时使用 8010 端口，产品行为一致）。

### 3) 自动化回归脚本
```bash
source .venv/bin/activate
python reports/run_qa_rounds_v2.py > reports/qa-rounds-v2.json
```

## 三、PM 视角可用性测试（定性）

### 通过项
1. **结构清晰**：阅读区与注释管理职责分离，认知负担低。
2. **路径顺畅**：上传 -> 点击词 -> 结果出现，无额外学习。
3. **状态可解释**：翻译中/完成/失败明确可见。
4. **错误可恢复**：失败后可重试，不会“死注释”。
5. **跨端一致**：桌面双栏、移动抽屉逻辑统一。

### 仍可优化项（非阻塞）
1. 重排模式的“已加入注释”提示可更细（显示词义而非文案）。
2. 注释列表尚无筛选（按页码/状态）。
3. 未实现批量导出。
