# Iteration 2 — 2026-02-13 (07:00–09:00 PST)

Goal: push the app from “demo” to “usable for real reading + translation workflow”, while keeping:
- Original + Reflow modes
- click-to-translate UX
- local-first (no login/cloud)

Test target: `testdata/war-and-peace.pdf` (2299 pages)

---

## Feature 1 — Local Bookshelf (multi-book list + last read)

### What shipped
- New **Bookshelf** dropdown in the top bar.
- Persists a **local list of opened books** (by pdf fingerprint) with:
  - title / filename
  - last opened date
  - last read page
  - total pages (if known)
- On load, sidebar restores **last opened book metadata + annotations** even before you re-upload the PDF.
  - (Reading still requires re-uploading the PDF bytes; this is expected for local-first / no filesystem access.)

### Acceptance criteria
- After opening a PDF, Bookshelf dropdown includes it.
- Refresh → Bookshelf still shows entry, and sidebar title/annotations restore.
- When scrolling, last read page is updated and shown in Bookshelf.

### Test steps (War and Peace)
1. Open app, upload `war-and-peace.pdf`.
2. Confirm Bookshelf shows `war-and-peace · p1 · 2026-02-13`.
3. Scroll; verify current page changes are persisted.
4. Open a new tab and confirm Bookshelf still lists War and Peace.

### Result
- PASS.

Notes:
- Switching to a bookshelf entry without uploading the PDF shows a hint “re-upload required”, but keeps the vocab/annotation workflows available.

## Feature 2 — Per-book Vocab panel + “Known word” toggle + hide-known

### What shipped
- New sidebar tab: **词汇 (Vocab)**
- Aggregates annotations into a per-book vocab list:
  - word, Chinese translation, count, last seen page
- **Known word** toggle:
  - from Annotations card and Vocab card
- **Hide known** checkbox to declutter review list.
- Optional **Auto-mark known** setting:
  - lightly marks known words in Original text layer and Reflow tokens.

### Acceptance criteria
- Any created annotation adds/updates a vocab entry.
- Marking a word known persists across refresh.
- Hide-known removes known entries from list.

### Test steps (War and Peace)
1. Click a word on page 4 (e.g., “Prince”).
2. Switch to 词汇 tab → confirm `1 words` and entry is present.
3. Click “标记已掌握” → confirm it becomes known.
4. Enable “隐藏已掌握” → vocab list becomes empty.

### Result
- PASS.

## Feature 3 — Export/Import vocab+annotations JSON (local backup & portability)

### What shipped
- New buttons in sidebar header:
  - **导出**: downloads a JSON bundle of current book data (glosses + knownWords + settings).
  - **导入**: imports that bundle into the currently-open book (merge by annotation id; union knownWords; merge settings).

### Acceptance criteria
- Export downloads a JSON file with expected structure.
- Import updates local state without crashing.

### Test steps
1. Open War and Peace, create at least 1 annotation.
2. Click 导出 → verify a JSON file downloads.
3. Click 导入 and choose the exported file → verify annotations/vocab still present.

### Result
- PASS (manual download + import flow).

## Feature 8 — Auto-translate modes (Reflow) (underline unknown / limit auto)

### Acceptance criteria

### Test steps

2. Settings → choose Underline unknown. Verify visual marking.
3. Settings → choose Auto-translate up to 10 per page. Verify up to ~10 badges on a page.

### Result
- PASS (best-effort; subject to translation backend availability).

## Known issues / follow-ups

- Marking known words in Original mode is best-effort (text layer spans can contain multiple tokens).
