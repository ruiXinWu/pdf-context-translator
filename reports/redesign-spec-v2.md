# PDF Context Translator 重设计规格（V2）

## 0. 目标
在不改变“点击英文词 -> 中文翻译”核心价值的前提下，把产品从 MVP 升级为可持续使用的阅读工具：
- 更清晰的布局层级
- 更可控的注释状态
- 更稳定的翻译失败处理
- 更完整的桌面/移动一致体验

---

## 1) 信息架构（IA）

### 顶层结构
1. **Topbar（吸顶）**
   - 文件上传
   - 页数状态
   - 全局状态提示
   - 模式切换（原始 PDF / 重排阅读）
   - 上一页/下一页
   - 跳转页码
   - 移动端注释面板开关

2. **Reader Canvas（主阅读区）**
   - 原始 PDF 渲染层 + 可点击 textLayer
   - 文内轻量翻译气泡（锚点附近）
   - 重排阅读段落（token 可点击）

3. **Annotation Panel（注释管理区）**
   - 注释卡片列表（词、页码、状态、译文）
   - 操作：定位、重试（错误态）、删除
   - 当前文档注释清空

---

## 2) 交互模型

### 主流程
- 用户上传 PDF -> 渐进渲染页面
- 点击英文词 -> 创建注释（loading）
- 翻译成功 -> 注释更新为 done
- 翻译失败 -> 注释更新为 error + 提供重试

### 双向联动
- 侧栏“定位” -> 跳到对应页
- 页内点击 -> 侧栏新增注释卡片

### 页面导航
- 上一页/下一页
- 输入页码跳转（支持目标页未渲染时重试定位）

---

## 3) 视觉层级

1. **第一层：正文内容**（最高关注）
2. **第二层：轻工具控件**（topbar）
3. **第三层：注释详情管理**（侧栏）
4. **第四层：临时提示/错误文本**

视觉策略：浅色背景 + 白色卡片，蓝色作为交互主色，错误态统一红色语义。

---

## 4) 桌面 / 移动行为

### Desktop（>=940px）
- 双栏：阅读区 + 330px 注释侧栏常驻
- Topbar 吸顶

### Mobile（<940px）
- 单栏阅读
- 注释区变为底部抽屉（按钮唤起）
- 保持上传、模式切换、翻页、跳转可用

---

## 5) Sticky Controls 规范
- Topbar 全局吸顶
- Panel Head 在面板内吸顶（列表滚动时操作不丢失）
- Reader 区独立滚动，避免整页滚动造成定位误差

---

## 6) Go-to-page 设计

输入约束：1 <= page <= totalPages

失败处理：
- 无效输入：状态提示“请输入 1-N 页码”
- 目标页尚未渲染：自动重试（最多 12 次，180ms 间隔）

结果：尽可能保证“输入即到达”的用户预期。

---

## 7) 翻译注释模型（Translation Annotation Model）

```json
{
  "id": "anno_xxx",
  "pageNum": 12,
  "word": "battle",
  "sentence": "...",
  "status": "loading|done|error",
  "wordZh": "战役",
  "contextZh": "战斗（语境）",
  "anchorX": 120,
  "anchorY": 340,
  "anchorW": 16,
  "anchorH": 10,
  "x": 140,
  "y": 338,
  "placement": "right|below",
  "version": 4,
  "createdAt": "ISO"
}
```

关键点：
- 既保存语义数据，也保存视图锚点
- 状态机显式化支持重试

---

## 8) 状态持久化

按 PDF fingerprint 本地存储：
- 注释集合
- 阅读模式（original/reflow）
- 当前页
- 版本号（v4）

恢复策略：
- 打开同一 PDF 自动恢复
- 版本不兼容时尽量容错读取 glosses

---

## 9) 失败处理（Failure Handling）

### 翻译 API 异常
- 文内气泡与侧栏卡片都显示 `Error: ...`
- 状态设为 `error`
- 提供“重试”按钮

### 输入异常
- 页码非法 -> 状态提示

### 渲染延迟
- 页码跳转自动重试

---

## 10) 非目标（V2 暂不做）
- 多人协作与评论线程
- 云端账号同步
- 注释导出（Markdown/CSV）
- 词汇记忆曲线与学习计划

---

## 11) 实现映射
- `app/static/index.html`：新 IA 与响应式布局
- `app/static/app.js`：状态机、侧栏管理、持久化、失败重试、跳页增强
- `testdata/war-and-peace.pdf`：QA 基准样本
